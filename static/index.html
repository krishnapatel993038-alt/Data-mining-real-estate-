Data Mining Regression Analysis

1. Simple Linear Regression (SLR)

Estimates price \(\hat{y}\) based exclusively on living area \(x_{sqft}\) using Ordinary Least Squares (OLS):

$$\hat{y} = \beta_0 + \beta_1 x_{sqft}$$

Where \(\beta_1 = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}\) and \(\beta_0 = \bar{y} - \beta_1 \bar{x}\).

2. Multiple Linear Regression (MLR)

Incorporates an \(m\)-dimensional feature vector with one-hot encoded neighborhood indicators and binary amenity vectors:

$$\hat{y} = \beta_0 + \sum_{j=1}^{m} \beta_j x_j + \epsilon$$

3. Polynomial Regression (Degree 2)

Captures non-linear compounding returns and feature interactions (\(x_i \cdot x_j\)), such as high sqft combined with prime location having an exponential multiplier on price.

4. Random Forest Regressor

Ensemble of 100 de-correlated decision trees mitigating variance through bagging and random feature subsampling. Capable of discovering non-linear price frontiers.

Evaluation Metrics Computed

  • \(R^2\) Score: Proportion of price variance explained (\(1 - \frac{SS_{res}}{SS_{tot}}\)).
  • RMSE: Root Mean Squared Error, penalizing large valuation deviations.
  • MAE: Mean Absolute Error in actual dollars.
  • MAPE: Mean Absolute Percentage Error.

Artificial Intelligence Constraint Satisfaction Problem

Formal CSP Formulation

Defined as a triplet \(\langle X, D, C \rangle\):

  • Variables \(X\): Target Property Selection \(P\).
  • Domains \(D\): Finite set of catalog inventory items \(D(P) = \{p_1, p_2, \dots, p_N\}\).
  • Constraints \(C\): Hard and Soft conditions specifying acceptable assignments.

Hard Constraints (Inviolable)

  • \(C_{budget}(P): \text{price}(P) \le \text{max\_budget}\)
  • \(C_{location}(P): \text{location}(P) \in \text{preferred\_locations}\)
  • \(C_{bedrooms}(P): \text{bedrooms}(P) \ge \text{min\_bedrooms}\)
  • \(C_{bathrooms}(P): \text{bathrooms}(P) \ge \text{min\_bathrooms}\)
  • \(C_{amenities}(P): \text{essential\_amenities} \subseteq \text{amenities}(P)\)

Forward Checking (AC-3 style Domain Pruning)

Whenever a constraint is registered, forward checking eagerly scans property domain \(D(P)\) and prunes any assignment that violates consistency, shrinking domain size instantaneously from \(N \to N' \to N''\) without costly exhaustive backtracking.

Soft Constraint Relaxation & Scoring

When preferences yield an over-constrained state (\(|D(P)| = 0\)), our engine engages tiered relaxation:

  1. Tier 1: Budget expansion by +10% or allow 1 missing essential amenity.
  2. Tier 2: Budget expansion by +20% or 1 fewer bedroom tolerance.
  3. Satisfaction Scoring: Weighted combination of base compliance, desired amenity coverage bonus, and proximity bonus.
